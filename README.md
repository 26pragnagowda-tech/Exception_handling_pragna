Python Exception Handling

Description

This project demonstrates exception handling in Python using "try", "except", "else", and "finally". It helps prevent unexpected program termination and displays meaningful error messages when invalid input or runtime errors occur.

Features

- Handles invalid numeric input.
- Prevents division by zero.
- Validates missing name input.
- Handles invalid list indexes.
- Handles missing files.
- Uses specific exception types.
- Demonstrates the "try", "except", "else", and "finally" blocks.

Technologies Used

- Python 3
- VS Code or IDLE

How to Run

1. Save the program as "exception_handling.py".
2. Open the file in VS Code or IDLE.
3. Run the program.
4. Enter the requested inputs and observe the output.

Learning Outcomes

This project improves understanding of runtime errors, exception handling, input validation, and writing reliable Python programs.
